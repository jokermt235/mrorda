# midterm_calculator_app

Flutter project - Calculator App

## Getting Started

This Flutter application features a sleek, iOS-inspired calculator with a login screen.

Features
- UI: Uses black, grey, and orange color scheme.
- Login Page: Users enter a username and password before accessing the calculator.
- Mathematical Evaluations: Supports basic arithmetic operations.

Technologies Used
- Flutter
- Dart
- math_expressions package (for evaluating mathematical expressions)

How to Run
- Clone the repository.
- Install dependencies using flutter pub get.
- Run the app using flutter run.
